## Status Key

| Icon | Meaning |
|---|---|
| ✅ Playable | Runs well end-to-end, minor issues at most |
| ⚠️ Ingame | Boots and runs but has noticeable issues |
| 🔶 Menus | Only title screen / menus work |
| ❌ Broken | Crashes, black screen, or doesn't boot |

## Submitting a Report

Open a GitHub Issue with:
- Game title and disc ID (shown in Cascade's game detail view)
- iOS device model and iOS version
- What happens (boots? crashes? graphical glitches?)
- Any error messages shown
