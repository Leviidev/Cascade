# Contributing to Cascade

Thank you for your interest in contributing! All PRs and contributions are welcome.

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Open a Pull Request

## Areas to Contribute

- **Emulation accuracy** — CPU, GS, SPU2, CDVD improvements
- **Game compatibility** — Report or fix games that don't boot
- **UI/UX** — Design improvements, new controller skins
- **Performance** — JIT recompilation, Metal GPU optimizations
- **Documentation** — Compatibility list, usage guides

## Code Style

- Swift 6, SwiftUI-first
- Follow existing file structure
- Add comments for emulation-specific logic

## Reporting Bugs

Open a GitHub Issue with:
- Device and iOS version
- Game title and disc ID
- Description of the problem
- Steps to reproduce
